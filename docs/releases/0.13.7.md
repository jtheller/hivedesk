# 0.13.7

The Intel hardware qualification probe now sizes its output bitstream from
GetVideoParam after encoder initialization, including BRCParamMultiplier.
A fixed 4 MiB allocation could fail with MFX_ERR_NOT_ENOUGH_BUFFER on real
Media SDK 1.35 hardware even when codec initialization succeeded. Allocations
remain bounded to 64 MiB and use checked 64-bit arithmetic.

Reports include the runtime buffer requirement and effective target bitrate,
and mark actual HEVC 4:4:4 encoded output separately from decoder qualification.
Regression coverage checks multiplier handling, default values and oversized
runtime requirements. Production NVIDIA encoding, decoding, session management
and Intel software receiving remain unchanged.
