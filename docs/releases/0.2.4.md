# 0.2.4

- Color-conversion PTX now targets Maxwell (`sm_52`) instead of requiring
  Turing (`sm_75`). The scalar kernels do not need Turing instructions; their
  architecture floor must not exclude older NVENC-capable GPUs. PTX remains
  version 6.4 and uses only the CUDA driver API, with no toolkit runtime.
- Failed color-kernel loads report the GPU name, compute capability and actual
  JIT compiler error in the ordinary user log. DEVR's observed startup failure
  was CUDA 218 during PTX loading; the additional detail distinguishes an
  architecture mismatch from driver/compiler installation problems.
- Blocking control writes advance in 16 KiB chunks. A native-resolution
  snapshot may take longer than the socket timeout overall while making
  progress; a truly stalled write still times out. Packet framing and the
  separate video/input channels are unchanged.

Regression coverage adds a real TCP transfer throttled to outlast its write
timeout, byte-integrity verification, and a reader-stall timeout check.

Validation: native and WinUI release builds succeeded; 32/32 native CTest
checks passed, including generated-image GPU color/codec round trips and the
throttled control-write test. DEVR requires this update and another live probe
to confirm its specific JIT failure is resolved.
