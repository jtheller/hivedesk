# 0.16.0

Adds a compact performance strip and matching connection/status visuals.

- Ctrl+Alt+I toggles this viewer's compact stats. The 352 x 28 DIP strip uses
  12 px Segoe UI, translucent rounded backing and a fine border. It is
  click-through and does not take focus. It shows presented FPS, encode (E)
  and decode (D) milliseconds, and received Mbps. Missing/stale samples show
  `--`; these are stage measurements, not end-to-end input latency.
- Performance warnings replace the state label inside the same row and tint
  affected metrics. With stats off, the existing delayed warning still appears
  as a smaller strip in the same top-left position. Warning hysteresis is
  unchanged. Connecting/reconnecting uses the same styling and anchor, with
  a blue state, device name and cancel shortcut. Its existing hint delay,
  native snapshot cover and first-frame transition remain in place.
- Ctrl+Shift+Alt+I toggles only the deepest viewed link. For A -> B -> C -> D,
  C toggles the stats for C -> D; A and B retain their own stats state. With
  only A -> B, A toggles. Every computer in the chain needs this release.
  Separate capability-gated control messages reuse the authenticated session,
  ordered input-release barrier and bounded nested-operation lifecycle. No
  simulated shortcut is injected into remote applications. Stale, revoked,
  duplicate, unsupported and timed-out operations cannot toggle another view
  or close a viewer. Secure-desktop requests fail closed.
- The large Debug overlay remains available in Settings. Turning compact stats
  on switches detailed debugging off through the existing saved-preference
  path. Compact visibility lasts for the app process; logs remain independent.
  Both stats chords are reserved; a previously conflicting custom Hive shortcut
  falls back to Ctrl+Alt+H on load.
- The strip uses cached CPU-rendered alpha surfaces, not a live backdrop blur.
  Unchanged content is not resubmitted to the compositor. No new video GPU
  device, frame capture/readback or blur pass is introduced.

Verification includes native alpha/DPI/Unicode/freshness rendering checks,
isolated actual keyboard-hook and Shell tests, A-B-C-D state-machine tests,
wire capability/malformed-message checks, shortcut migration and the existing
waiting/snapshot suite. Release packaging gates publication on the complete
native suite, managed bridges and WinUI light/dark checks. Real multi-computer
nested viewing and subjective appearance remain user acceptance checks.

NVIDIA/Intel/AMD codec selection, HEVC 4:4:4, bitrate control, video queues,
render pacing and capture/input formats are unchanged. Idle-only signed OTA
retains its active-session protection.
