# 0.13.3

The reconnect snapshot retains the selected computer's last known display name
when it leaves discovery during a reboot. It no longer displays the internal
device ID. Rediscovery/rename refreshes that name; selecting another computer
replaces it and returning locally clears it. An unnamed peer uses "Remote
computer". Connection recovery and all media/input policies are unchanged.

The isolated waiting-screen check covers discovery removal before reconnect,
rename followed by another removal, and renderer renewal with the retained name,
alongside existing selection, snapshot, cancellation and late-frame checks.
