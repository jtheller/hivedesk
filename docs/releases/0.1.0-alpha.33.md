Add a **Prefer maximum GPU performance** checkbox for local NVIDIA power-policy comparisons.

- Enabling applies NVIDIA's prefer-maximum-performance application setting to
  HiveDesk's host and viewer processes. Disabling restores their previous
  explicit setting, or removes the override to restore inherited policy.
  Global driver settings, display refresh rates and codec parameters are unchanged.
- The checkbox reads the driver configuration and reports unsupported drivers,
  conflicts and failed writes. Original policy is journaled before changes;
  restoring does not overwrite a later external policy change.
- Changed profiles request a graceful restart of the local video processes when
  inbound/outbound, starting and reconnecting sessions are idle. Existing remote
  sessions are allowed to finish. Windows does not need to restart.
- This is a diagnostic preference, not a fixed clock or P-state guarantee.
  Compare the same changing desktop scene with the host option off and on, then
  test the viewer separately. Higher power use is possible while enabled.

Validation: 27/27 native checks, managed GPU/update bridge tests and isolated
WinUI light/dark checks passed. A real NVIDIA driver probe verified write/readback,
exact restore and cleanup using temporary application profiles; actual HiveDesk
profiles were unchanged. Real VI/DEVG performance comparisons remain a user
acceptance test; this release does not claim to fix the observed stutter or
establish its cause.
