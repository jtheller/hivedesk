# 0.2.1

Transient delays no longer tear down otherwise usable remote sessions at LAN-only
100/150 ms thresholds. Input capture, send completion, injection ACKs and desktop
broker admission now share a 2-second stall watchdog with video writes and viewer
freshness recovery. Update both computers: older builds retain their old limits.

Frame freshness dropping, adaptive CBR/pacing, adjacent mouse-motion coalescing,
eight input credits, two video writes in flight and one unsent video slot remain.
The longer watchdog does not enlarge playback queues. Genuine socket failures,
revoked sessions and rejected Windows input still fail immediately; seconds-old
input is released instead of replayed. LAN discovery/firewall scope is unchanged.

Regression coverage includes 400 ms delayed encrypted input ACKs, subsecond
capture/broker key-down/up ordering, and stalled encrypted video/input surviving
400 ms before seconds-scale cancellation and held-input cleanup. Tests use mock
injection and loopback sockets, not the user's desktop. Physical VPN behavior
requires a two-computer check.

Validation: all 32 native CTest checks passed; native and WinUI release builds
completed successfully.
