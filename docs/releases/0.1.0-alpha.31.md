Correct pipeline scheduling and freshness decisions while preserving native
resolution, HEVC 4:4:4, physical monitor refresh rates and bounded work queues.

- Encoder throughput is no longer inferred from an isolated frame's residence
  latency. Only actual GPU-slot pressure beyond a scheduled capture deadline
  supplies NVENC capacity evidence. Healthy paced completions, network waits,
  recovery and reconfiguration drains cannot manufacture encoder overload.
  Saturated evidence expires; one old spike cannot become repeated bad samples.
- Video frames carry their source encode-completion timestamp when both peers
  support it. Intrinsic source work no longer consumes the transport-backlog
  budget, so a slow valid encode does not repeatedly invalidate subsequent IDRs.
  Source work remains bounded, and timestamps cannot be renewed after queuing.
  Real stale TCP tails, local queue expiry, gaps and duplicate frames retain
  their protection. This is not a guarantee of 50ms total image latency.
- Health and diagnostic reports use a bounded latest-only mailbox with a
  separate pipe writer. Capture/submission never waits for status I/O. Shutdown
  cancels blocked writes before joining; video backpressure remains enabled.
- Receiver NVDEC submission and mapping run independently with at most two
  pictures in flight. Decode indices remain owned until unmapping completes.
  Conversion publishes into three bounded RGB surfaces; a separate presenter
  waits for display capacity, then chooses the latest completed picture.
  Superseded display images are replaced without discarding encoded references.
  CUDA registrations are cached for those surfaces, including size changes.
- Decoder map/conversion latency remains visible in diagnostics but no longer
  supplies a guessed throughput ceiling. Actual compressed-picture backlog
  drives receiver pressure, with a short bounded observation retained across
  dequeue/recovery so feedback cannot miss the overload.
- Late decoded output can request a fresh picture without invalidating the
  still-valid reference chain. Compressed admission retains its strict expiry
  and bounded recovery. A fresh subsequent P picture can clear an output-only
  refresh request. Rendering selects the primary monitor's adapter explicitly.
- The HUD labels NVENC residence as latency. Its source transit metric follows
  receiver feedback, which excludes encode work for the new timed-frame path.
  Successful Present calls are still not a measurement of physical scanout.
