Add **Check for updates** beside the version in Settings.

- The action checks the latest signed release immediately, shows progress and
  distinguishes an up-to-date installation, an update request and an unavailable
  updater. Failures are shown as failures; duplicate clicks are coalesced.
- A newer release wakes the existing SYSTEM updater's scheduled check through
  a separate owner-verified event. The UI cannot supply an installer or URL and
  does not launch installation itself. Signature, hash and idle-session checks
  remain in the existing automatic update path.
- Closing Settings cancels its transient check helper. Downloads and installation
  in the SYSTEM worker remain independent. The check has a bounded timeout.
- The fixed Settings window retains its size and existing controls. This release
  leaves the alpha.31 video pipeline unchanged.

Validation: 25/25 native CTest checks, managed bridge protocol/error/timeout/
cancellation checks, and real WinUI light/dark layout and action-state checks
passed. WinUI tests ran on a private non-input desktop. The native manual-check
helper also verified the public signed release. Tests did not interrupt remote
sessions, signal the installed updater or run a new live installation cycle.
