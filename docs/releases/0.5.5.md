# 0.5.5

Every new Hive opening starts with the sidebar above the taskbar. Reset the
previous temporary taskbar lease and fade when opening by hotkey, entering the
mouse preview, or reopening during dismissal. Remove the previous behavior that
kept the taskbar above a newly opened Hive.

The bottom-left trigger still raises the native taskbar for the current cycle.
Moving away, dismissing the sidebar or toggling it closed does not restore the
old layering. The next opening resets it. Explicit viewer activation, device
selection, return-local and shutdown retain their normal input/z-order cleanup.
If the pointer is still in the bottom corner at reopening, require it to leave
and re-enter before triggering again. Both native and captured Hive hotkeys can
reverse an in-progress dismissal instead of losing the reopen request.

Regression coverage includes normal and rapid hotkey reopening, pointer preview
and expansion, stale dismissal timers, stationary-corner rearming, outside-click
pass-through, clipboard handoff, input routing and existing viewer/session tests.
Validation uses the full native/managed/WinUI suite, three repeated lifecycle
runs and serial GPU/DWM/loopback probes. Physical Explorer Start-menu clicks and
two-machine long-duration interaction remain separate real-machine acceptance.
