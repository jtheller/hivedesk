# 0.5.2

Add a local taskbar hot corner at the bottom-left of the fully expanded Hive
switcher. Entering the corner immediately raises the native Windows taskbar.
The taskbar remains accessible while the pointer travels along it to a centered
Windows 11 Start button, or while Start/Search is open. Moving back into Hive
restores the previous layering. This does not automatically press Start or
change the remote session.

Both transitions crossfade over 180 ms using a temporary, input-transparent
snapshot strip owned by HiveDesk. Explorer's transparency, geometry, taskbar
alignment and auto-hide settings are not changed. Windows' disabled-animation
preference is respected. Closing Hive, selecting a device or shutting down
removes the temporary layer and restores the taskbar lease immediately.

Remote keyboard/mouse interception is suspended during local taskbar use, with
held remote keys/buttons released. Start/Search receives Escape normally;
taskbar clicks do not dismiss Hive or reach the remote machine. Opening a local
application does not force focus back to the viewer; remote interception resumes
after viewer focus returns.

Validation includes an isolated-window-station taskbar fixture for z-order,
geometry, DPI boundaries, centered Start reachability, rapid reversal and
Explorer-window destruction; a real-DWM generated-color fixture checks visible
crossfades in both directions without touching Explorer, moving the pointer or
activating a window. Input worker tests verify release and resume boundaries.
Actual Explorer/Start-menu and auto-hide interaction remain for user testing.

All 39 native CTest checks, Settings update/GPU-policy checks and light/dark
WinUI tests passed. The five affected input/shell checks were rerun after final
handoff changes; the generated DWM entry/exit pixel checks also passed.
