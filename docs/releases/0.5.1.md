# 0.5.1

Remove the fixed two-write application ceiling on observable high-RTT video
connections. Additional overlapped sends are admitted by bytes, using the
minimum of Windows' ideal send backlog, TCP congestion window and receive
window. Fast connections retain two writes. Missing/invalid observations or
more than 50 ms of RTT growth above the measured minimum revert to two writes;
already submitted bytes drain in authenticated order. Expanded ownership is
bounded to 32 writes and a 16 MiB budget. The original two writes remain allowed
for large IDRs, even when the byte budget is smaller than those frames.

The one unsent slot, 50 ms unsent expiry, dependency recovery and two-second
no-new-TCP-payload watchdog remain. This is a bounded in-flight window, not an
additional frame playback queue. No address, subnet or VPN exception is added.
Local video_send diagnostics now include the write limit, owned/budget bytes,
RTT/minimum RTT, ISB, congestion/receive windows, TCP bytes in flight and sample
age. No peer wire format changes are required.

Extend the independent Intel media probe with `--intel-roundtrip`: generated
4:4:4 patterns, managed D3D11 surfaces, asynchronous encode/decode and actual
HEVC SPS inspection. It rejects reduced chroma and reports decoded Y/U/V error.
This remains an explicit diagnostic; AMD/Intel production streaming is not
enabled. Existing NVIDIA encoder/decoder settings and dependencies are unchanged.
See `docs/MEDIA-BACKENDS.md` for hardware requirements and remaining integration.

Validation:

- All 38 native CTest checks, Settings update/GPU-policy bridge tests and
  light/dark WinUI self-tests passed. The generated real-DWM warm activation
  probe presented the fresh image and repeated cadence without extra encoding.
- Production agent/host import inspection found no AMF/VPL runtime dependency.
- Real encrypted TCP loopback holds eight overlapped writes, verifies received
  contents/order, and separately cancels eight outstanding owners safely.
- A deterministic 100 ms ownership model removes the two-write throughput
  ceiling (40 to 200 supplied frames in two seconds). This is not a physical
  network benchmark or proof of DEVR performance.
- Budget tests cover LAN behavior, congestion/receive window limits, pressure
  shrink, invalid RTT and overflow. Telemetry checks cover units and session
  isolation. SPS checks cover real NVIDIA HEVC 4:4:4, reduced chroma, depth,
  crop, sublayers, malformed, conflicting and truncated input.
- Intel roundtrip reports SKIP on DEVG because no Intel adapter is installed.
  AMD/Intel hardware results and live high-latency motion remain pending.
