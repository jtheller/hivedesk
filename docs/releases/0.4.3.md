# 0.4.3

Fix a regression introduced by visible-peer prewarming: selecting a prepared
computer ended the connection after about two seconds. The broker's frame-kind
validator rejected the newly added Activate and Activated messages, so the
retained encoder never resumed through the installed service.

- Accept activation and its acknowledgement on the media broker pipe. Wake
  activation waiters promptly when that pipe closes; input admission stays gated.
- Negotiate a new warm capability. Both endpoints must run 0.4.3 or later;
  mixed pairs with 0.4.0-0.4.2 use ordinary cold starts during the rollout.
- Test the activation exchange over actual named pipes and reject the old warm
  capability. Add an explicit installed-main-app --warm-broker-check probe for
  SYSTEM capture, one-frame pause, activation ACK and fresh sequenced IDR. This
  probe sends no keyboard, mouse or clipboard events and cannot displace an
  existing broker session.

Includes the all-visible preparation and event timing traces introduced in
0.4.0. Codec, quality, bitrate policy and physical refresh rates stay unchanged.
Real bidirectional motion and input-to-photon acceptance remain pending.
