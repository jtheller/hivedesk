Move Relative mouse to Settings, add a tray restart action, and expose both
endpoint versions in the debug overlay.

- Relative mouse is now a checkbox saved with the other preferences. It persists
  across restarts, defaults off for older settings and is removed from the tray
  menu. The native fallback Settings supports the same preference.
- Restart HiveDesk in the tray menu ends current sessions through normal
  shutdown, releases input and starts a replacement after the old process exits.
  Manual restart returns quietly to the tray.
- Debug starts with Viewer (this PC) and Host (remote) version rows. Mismatches
  are amber. Both endpoints need alpha.36 or newer to exchange versions; older
  peers remain compatible and show Unknown.

Validation: 30/30 native checks, managed bridge checks and private-desktop WinUI
light/dark checks passed. Version exchange was exercised through encrypted
loopback, restart ordering through isolated subprocesses, and HUD labels through
hidden rendering at 100/150/200 percent DPI. No live desktop input was injected.
