# 0.16.4

Fixes compact stats blinking between values and gray placeholders when the
remote desktop stops changing. Previously, no new frame for 500 ms was treated
as unavailable telemetry, so every intermittent frame restored the text and
icons only for them to fade back to placeholders.

FPS and bitrate now keep showing the actual rolling rates, including zero.
Encode and decode latency show the latest completed measurement in the current
session, without expiring merely because there is no new frame. Missing host
telemetry still expires the encoder reading after two seconds. A new session
starts without invented timings. Detailed debug sample-age reporting is unchanged.

The regression checks unchanged HUD pixels across five seconds of static
content at 16 ms ticks, immediate reading updates on resumed motion, missing
host reports, and an empty new session. This is a compact HUD presentation fix;
video pacing, codecs, network transport and input routing are unchanged.
