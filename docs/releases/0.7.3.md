# 0.7.3

- Remove the Settings Save button. Toggles save immediately; the computer name
  saves after a 350 ms typing pause or on leaving the field.
- Serialize saves and coalesce edits made while awaiting acknowledgement, so
  rapid changes cannot restore an older value. Show compact saving/saved status
  and actionable errors instead of a success banner after every edit.
- Flush pending edits before closing Settings or applying a GPU policy that
  restarts HiveDesk. Preserve the last confirmed settings on failure and offer
  retry; closing with unsaved changes offers an explicit discard action.
- Apply automatic saving to the native fallback settings window as well.
- Strengthen cadence diagnostics with continuous static-pixel and changing-frame
  checks on ordinary and composed presentation paths. The reported full-screen
  black flashes with Steady cadence enabled remain unresolved; keep it disabled.

10-bit streaming is not included in this update.
