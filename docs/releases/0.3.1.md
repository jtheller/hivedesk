# 0.3.1

Emergency repair for the 0.3.0 switcher/windowed-viewing regressions.

- Move waiting-cover layout out of synchronous WM_SIZE/WM_MOVE handlers. DXGI
  can send these while holding graphics locks; entering DirectComposition from
  that callback risks blocking video startup or resize. Coalesce layout on the
  UI queue, skip GPU uploads for movement alone, and preserve first-frame fades.
  Add selection/startup/graphics-ready/stream-requested log stages so another
  startup stall can be located rather than silently remaining on Connecting.
- Fix DirectComposition sibling ordering: the opaque backing previously sat
  above the animated cards. Hotkey cards now visibly enter from the full left
  edge, fading in with a bounded stagger; all finish in 240 ms. Mouse hot-corner
  background behavior remains unchanged.
- Dragging now shows the actual card snapshot following the pointer, including
  its machine-name badge. Adjacent cards move aside over 140 ms. Edge scrolling
  rebuilds the visible layers; dropping commits the new order without briefly
  restoring the old bitmap. Cancel/drop removes the non-activating ghost.
- Retain foreground ownership when a click/drop starts viewing, instead of
  activating the previous application immediately before opening the viewer.
  Floating viewers start at up to 84% of the work area, constrained by the
  source aspect ratio, rather than a small 1100-pixel maximum. Normal clicks
  continue to open fullscreen.

Validation: 33 native CTest checks; isolated-window-station real asynchronous
DXGI startup, NVENC/NVDEC decode, resize and teardown across fullscreen/windowed
selections; drag-ghost existence/lifetime, persisted ordering, minimum initial
size, deferred layout, and existing stale-surface/session regression checks.
The synchronous-composition regression fails against the 0.3.0 shell and passes
with this fix. An explicit generated-content check on visible DWM (no input
injection or foreground activation) verified staggered rendered pixels, final
card visibility, animated insertion gap, and an actual first Present beneath
an opaque waiting cover. The isolated station itself cannot validate scanout.
Physical mouse feel and the user's intermittent two-computer stall still need
live observation after installation; the synthetic checks are not that claim.
VPN/DEVR transport behavior is outside this release.
