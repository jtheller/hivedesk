Live diagnostic overlay for investigating frame and input stalls.

- Visible debug HUD samples on the existing ~16ms UI timer, independent of the
  100ms receiver feedback loop. Windows scheduling can delay timer delivery.
- Source diagnostics publish at up to ~60Hz; encoding/color/NVENC times show the
  latest completed frame, including transition/keyframe spikes. Update both ends
  for fast source readings. The capture/encode loop can delay source reports.
- FPS and bitrate use bounded 250ms rolling windows. The adaptive bitrate and
  pacing controller retains its existing samples and cadence.
- Per-metric amber/red warnings; stale or idle samples are gray. Stage thresholds
  follow the target frame budget. Drop counters flash only on new increments;
  low FPS on an unchanged desktop is not itself an error.
- Added map/convert/draw, presentation-gap and input queue readings. ACK timing
  is roundtrip, and presentation timing does not measure monitor scanout.
- Rounded 62%-opaque background with independently opaque text; remains in the
  top-left, nonactivating and click-through. No input hooks or hotkeys changed.
- Coalesced unsent diagnostic reports prevent telemetry backlog. On-disk history
  remains approximately once per second, not once per UI tick.

Validation: native build, headless regression suite and hidden-window alpha
compositing check. Live DEVG/VI visual and performance comparison remains a
two-computer acceptance check; development does not restart either live session.
