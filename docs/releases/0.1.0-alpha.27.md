HiveDesk now publishes its Windows installer through GitHub Releases and includes
automatic signed updates.

- Install alpha.27 once on each computer to bootstrap OTA.
- The service checks releases every 15 minutes and downloads in the background.
- Installation waits until neither controlling nor being controlled, including
  pending starts/reconnects. Idle discovery connections do not block it.
- Signed installer verification, silent service-managed installation, no forced
  reboot, and restoration of the ordinary-user tray are included.
- Includes the alpha.25 independent input path and alpha.26 top-left Debug/status
  overlays, HEVC 4:4:4 and automatic bitrate selection.

Windows x64, NVIDIA HEVC 4:4:4-capable endpoints, trusted IPv4 LAN, primary screen.
This is alpha software. The first live SYSTEM OTA upgrade remains a post-bootstrap
acceptance check; headless tests are not a substitute for a real installation.
