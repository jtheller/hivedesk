# 0.4.2

Includes visible-peer prewarming, per-event experience traces and the request
identity guard from 0.4.0/0.4.1. Fix the explicit `HiveDeskCheck --warm` diagnostic
to traverse the running local tray app over its authenticated warm protocol.
The privileged broker correctly rejects direct access by diagnostic executables;
its existing main-app-only trust boundary remains unchanged.

The probe checks a real encoded picture, paused renewal and scoped cancellation
without input, clipboard or normal control Start. A busy host can refuse it.
`--warm-remote <IPv4>` performs the same read-only check on a specified endpoint.

Normal media, UI, encoding configuration and control behavior are unchanged from
0.4.1. The installed local app/broker/network prewarm path and a real DEVG-to-VI
warm request both passed: one picture, paused renewal and confirmed remote lease
release, without input injection. VI received 0.4.1 through its idle OTA before
the check. Physical bidirectional motion and input-to-photon acceptance are still
pending.
