# 0.12.0

Hive now hides computers that are directly or indirectly viewing this computer.
With A viewing B, B hides A. With A viewing B and B viewing C, C hides both A
and B. Releasing the viewing path restores devices in their saved order.
There is no new setting and no multi-viewer/feed-sharing change in this release.

Promoted viewing sessions and live Peek publish their incoming viewing ancestry
over a capability-negotiated encrypted control message. Background warmup does
not contribute an edge. Paths propagate along the actual chain, so indirect
ancestors do not need a direct network connection to every descendant. State
changes are versioned, coalesced, bounded and scoped to the current authenticated
connection; old announcements cannot overwrite newer state. Disconnects clear
the departed parent and propagate restoration.

Hidden devices leave the visible warmup/snapshot list. Removal cancels pending
drag and hover authority, hides active/fading Peek surfaces immediately, and
invalidates late preview completions. Saved ordering is preserved. Selection,
stream requests and live Peek admission also enforce ancestry, covering stale
UI actions rather than relying only on hiding cards.

Simultaneous requests can race network state propagation. If they form a cycle,
all participants identify the same cycle member by stable device ID. That host
revokes its conflicting inbound lease, sends session-scoped termination, releases
input and uses the independent cleanup worker. Its own unrelated outbound viewer
remains open. This is convergence after distributed state exchange, not a claim
that two disconnected state snapshots provide instantaneous global admission.
Existing per-event input-loop protection remains in place during propagation.

Upgrade all computers in the chain to 0.12.0 for full transitive protection.
Older peers retain their previous wire protocols and cannot relay ancestry.
Paths are limited to 64 entries; incomplete paths at that bound fail closed.

Validation covers real encrypted sparse three-node propagation, restoration,
cycle convergence, source disconnects, malformed/unsupported/stale announcements,
late connection messages, and concurrent publisher ordering. Isolated Shell
tests cover removal during hover/drag, stale fullscreen/window selection and
saved-order restoration. Actual App tests cover direct/indirect filtering,
restoration, cycle termination while retaining another outbound viewer, and
the existing rapid Peek, recovery, nested input and nested return regressions.
The fixtures do not inject input into the user's working desktop.

All 49 native tests, managed Settings checks and real WinUI light/dark checks
passed. The route, transport and actual App tests passed again after the final
connection-replacement and session-authority guards.
