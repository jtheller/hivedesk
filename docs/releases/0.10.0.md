# 0.10.0

Ctrl+Alt+physical backtick now returns one remote level. With A viewing B and B
viewing C, the first press returns B to its desktop while A keeps viewing B.
The next press returns A to its desktop. Ctrl+Alt+Backspace is the independent
emergency shortcut that returns directly to the physical local computer without
waiting for any network response. Ctrl+Shift+Alt+backtick still kicks this
computer's inbound controller.

Return operations travel over authenticated, capability-negotiated connections.
They are bound to controller leases, viewer sessions, selection generations and
operation IDs. Each hop first waits for the desktop broker to acknowledge an
ordered ReleaseAll input barrier, then asks the next host whether it has another
active view. Only the innermost viewer closes; input capture resumes on retained
outer views. Late input captured before the return cannot cross that boundary.

Repeated held shortcuts fire once. A pending operation does not admit additional
unwinds. Revoked controllers, old replies and duplicate requests cannot close a
new selection. Busy/cyclic routes and a 16-hop budget bound command forwarding;
they do not prevent nested connections. A ten-second local deadline restores
input admission without guessing another level to close. As with other network
operations, a timeout cannot undo an action already applied remotely.

All computers in the nested chain should run 0.10.0 or later. An older peer is a
compatibility boundary: escape retains the former local-return behavior there.
Connecting views can still be cancelled. Peek/prewarm is not a nested control
layer. This release adds nested **return control**, not general multi-hop input
relay or integration with another remote-control application's shortcuts.
Injected OS input remains excluded from physical hooks, retaining cursor-loop
and drift protections from 0.9.1.

Validation covers the pure A-B-C state machine, real encrypted request/reply
transport, malformed/unsupported packets, fixed physical hotkeys, and actual
Shell transitions on an invisible window station. The App integration test
withholds the input-release ACK to verify no return command is sent early, then
checks that a child-return keeps the outer viewer and a leaf-return closes it.
Real-machine multi-hop UX remains a separate acceptance check; no input is
injected into the user's working desktop by these tests.

Final validation: all 47 native CTest checks passed, as did managed Settings
update/GPU-policy checks and real WinUI light/dark checks. Prelogon tests cover
leaf replies and rejection of warm/wrong-session return requests. A logged-in
host on a secure desktop reports that visible login/lock screen as the leaf,
rather than unwinding a viewer hidden on its user's ordinary desktop.
