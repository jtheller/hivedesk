# 0.4.0

- Opening Hive now starts media preparation for every visible online computer
  that supports the new protocol, including newly visible cards after scrolling.
  Preparation creates the real capture/encoder, decodes one picture into a hidden
  viewer, then pauses encoding while retaining media resources. Selection reuses
  that decoder and HWND, activates the retained encoder and requests a fresh IDR.
- Warm leases are separate from control: no clipboard handoff or network input
  admission until selection, no replacement of an existing controller or another
  warm owner. Cancellation is session-scoped and cannot end a promoted session;
  late renewals cannot downgrade it. Offscreen leases have a two-second grace
  period and remote leases expire after ten seconds without renewal. Cold
  fallback releases unused warm decoders before allocating more GPU resources.
- Debug overlay now also enables bounded asynchronous per-frame/input CSV
  traces. Arrival, decoded/converted-ready and successful Present events can be
  correlated with individual input sends and injection ACKs. DXGI display
  observations include validity and identifiers; unavailable observations remain
  unavailable. No synchronous disk writes occur on the input/render producers.
  Diagnostic losses are counted, files rotate, and no key values, clipboard or
  image contents are recorded. Add an analysis script and measurement guide.
- Input diagnostics expose time blocked by the eight-packet ACK window. The
  credit policy remains unchanged pending real evidence. A busy viewer Present
  retry now uses the existing high-resolution timer instead of Sleep(1).
- HEVC 4:4:4 preset, rate-control policy, resolution and physical refresh rates
  are unchanged. Both endpoints need 0.4.0 for prewarming; older peers retain
  normal cold connections. Cached prepared pixels are not a live video promise.

Validation: native and WinUI release builds; 33 native CTest checks, including
new negotiated/malformed prewarm messages, encrypted loopback warm requests and
session-scoped cancellation, input-credit timing, and real hidden NVDEC + HWND
reuse on an isolated window station. Explicit MediaHost test verifies one-frame
pause, retained-encoder activation and fresh sequenced IDR. Generated-content
DWM presentation test passes without input injection or foreground activation.
The 1440p generated motion/hard-cut codec probe passes; trace analysis checks
retain long gaps, distinguish missing display observations, and compute event
percentiles rather than aggregating rolling-window percentiles.

Physical VI/DEVG continuous-motion and local-vs-remote input-to-display acceptance
remain pending. Injection ACK and Present submission are not input-to-photon
proof. See docs/EXPERIENCE.zh-CN.md for capture and interpretation boundaries.
