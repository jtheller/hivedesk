# 0.16.2

Compact stats now remember their on/off choice for each remote device, including
after restarting HiveDesk. Detailed debug takes precedence without changing
those choices: Ctrl+Alt+I does nothing while debug is enabled, and disabling
debug restores the selected device's compact-stats state.

Hold Alt and drag the compact stats strip to move it within the viewer. Positions
are retained per device during this app run and clamped to the visible viewer.
Standalone slow-stream warnings, connection/reconnection hints, error notices
and the detailed debug panel remain fixed. The capture worker owns the drag
gesture, releases remote held input and suppresses remote mouse/button delivery;
in relative mouse mode, Alt temporarily frees the local pointer for positioning.
Normal click-through behavior remains when Alt is not used.

The compact strip and notices use a 67% opaque background (171/255), preserving
opaque text. Selected status icons are the open ring with a dot for slow-stream
warnings, paired links for connecting, paired circular arrows for reconnecting,
and a circle with a slash for unavailable remote statistics. These are static
16 DIP icons; connection delay and existing fade timing remain unchanged.

Validation covers durable per-device preferences, debug precedence, failed-save
behavior, isolated hook gestures and cancellation across session changes,
fixed-notice drag exclusion, native rendering and the complete release suite.
No video codec, bitrate, frame pacing or transport policy changes.
