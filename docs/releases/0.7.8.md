# 0.7.8

- Retain the 0.7.7 fix that keeps desktop-service activation and diagnostics
  responsive while video waits for send credit.
- Correct the explicit installed broker regression's blocked-stop setup. A
  resumed frame can still own the single credit when the test closes its gate;
  demanding another frame then falsely fails correct backpressure. The probe
  now waits for the actual readiness predicate to observe that blocked gate,
  then checks prompt cancellation and bridge reuse. Normal streaming is unchanged.

Live DEVR evidence on 0.7.7: sender congestion window remained near 13,090 bytes,
RTT near 140 ms, receiver window 262,912 bytes, and about 10% of the counted
outbound bytes were retransmissions. The congestion-window/RTT estimate of
roughly 0.75 Mbps matches measured reception. Queued application data was
available throughout, while source diagnostics now continued during slow sends.
These are TCP transmission constraints, not evidence of an encoder/decoder
capability failure. Packet loss versus reordering and continuous playback remain
unresolved; this is not a claim that DEVR is now usable.
