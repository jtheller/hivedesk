# 0.4.1

Includes the visible-peer prewarming and detailed experience traces from 0.4.0.
Reject a warm request without a session identifier at the public transport API,
so invalid caller input cannot fall through to a legacy control Start. Valid
prewarming and ordinary connections are unchanged. Add an encrypted-loopback
regression for this boundary.

Both endpoints need 0.4.0 or newer for prewarming. HEVC 4:4:4 codec settings and
the input credit policy remain unchanged. Physical bidirectional sustained-motion
and input-to-display acceptance are still pending; see docs/EXPERIENCE.zh-CN.md.
