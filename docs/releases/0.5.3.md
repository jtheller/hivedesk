# 0.5.3

Make the bottom-left taskbar trigger stay open until an explicit action. Moving
the pointer away no longer restores the old layering or dismisses Hive. Remove
taskbar-boundary hysteresis and Start/Search process-name detection from this
decision, so crossing native menu windows cannot repeatedly switch modes.

Clicking or activating the remote viewer, closing Hive with its shortcut, or
choosing a device releases the temporary taskbar state. Animated dismissal keeps
the 180 ms taskbar crossfade; device changes and shutdown still clean up at once.
Keyboard and mouse remain local while the taskbar state is held, and launching
another local application does not force focus back to the remote desktop.

Revoke the taskbar lease before restoring foreground, because Windows can send
WM_ACTIVATE synchronously during that operation. Existing isolated taskbar,
input-worker, waiting-screen and viewer/session regressions cover the affected
paths; real Explorer interaction remains a separate user check.

Validation: all five affected native checks passed on the final build, as did
the generated real-DWM entry/exit crossfade pixel check without focus changes.
