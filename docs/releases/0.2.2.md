# 0.2.2

Switching from VI back to the local desktop and then to another computer could
briefly expose VI's last frame. The video HWND and snapshot composition target
were reused while their replacement cover was only asynchronously committed.

Each new selection now creates a fresh video window and waiting composition
target. The old video window is hidden immediately and kept alive only while its
renderer holds a lease; UI cleanup destroys it after the renderer stops. Late
first-frame notifications must match the selected window as well as the peer.
Returning to the local desktop hides video before removing the waiting cover.

Regression coverage uses an isolated, noninteractive window station: remote A,
local, remote C; old renderers still alive during selection; same-peer reselection
with late completion; stale close messages; and retired-window cleanup. This
checks window identity, visibility and lifetime without injecting desktop input.
Physical DWM scanout of the reported sequence still needs user verification.

The 0.2.1 seconds-scale stall watchdogs and existing snapshot/fade behavior remain.

Validation: 32/32 native CTest checks passed, including the extended waiting-screen
regression. Native and WinUI release builds completed successfully.
