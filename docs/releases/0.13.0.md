# 0.13.0

Ctrl+Alt+H (or your configured Show local Hive shortcut) still opens Hive on
the computer at your keyboard. Ctrl+Alt+Shift+H now opens Hive on the deepest
computer in the active control chain. With A viewing B and B viewing C, these
open A's Hive and C's Hive respectively. Return one level first to summon B's
Hive. Without an active outbound view, the remote shortcut opens local Hive.
Settings labels the local shortcut and displays the fixed remote shortcut.
The remote chord is reserved; an older local binding to it resets to Ctrl+Alt+H.
Press it again to dismiss that Hive. Outer layers fade out their own Hive/Peek
panels while forwarding, so they do not cover the requested inner panel.

Remote summon is an explicit capability-negotiated encrypted command, not
simulated keystrokes. It does not depend on the target's configured shortcut.
Each forwarding step waits for the ordered input ReleaseAll acknowledgement,
then checks the active view session and generation. The receiving endpoint
checks its current authenticated controller, input lease and desktop before
opening or forwarding. Warmup/Peek leases cannot summon Hive. Secure/prelogon
desktops reply unavailable rather than opening a hidden user's panel.

Summon and one-level return share the bounded operation/barrier machinery but
have distinct wire messages and reply types. Summon never closes a viewer.
Repeated commands, retired connections and stale replies cannot reopen a panel
or complete a different operation. Concurrent operations are rejected as busy;
the existing hop bound, timeout, cancellation and emergency local return remain.
Upgrade every computer in the chain to 0.13.0 for remote summon; older versions
remain connectable, and unsupported summon fails without closing the stream.

Validation includes isolated hook and Shell tests, three-layer operation state,
wire serialization and malformed/unsupported messages, prelogon refusal, and
the actual App over encrypted loopback with the input ACK deliberately held.
Existing rapid Peek, windowed selection, input relay, nested return and cycle
filtering regressions remain in the full suite. No synthetic input is sent to
the user's working desktop.
