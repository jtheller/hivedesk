# 0.3.0

- Hotkey summon keeps the switcher's 240 ms background fade and reveals cards
  from the left with individual opacity/translation animations. Stagger delays
  share the same total budget (up to 60 ms), so the last card also finishes by
  240 ms. DirectComposition evaluates the animations; snapshot uploads do not
  restart them. The Windows client-animation preference is respected. Mouse
  hot-corner entry retains its existing fade.
- Remote computers can be dragged to reorder, with an insertion marker and
  edge scrolling. The local computer stays first. Order is saved on this
  computer and survives rediscovery, restarts and temporary offline devices.
  Previously remote peers were listed by their random device IDs.
- Drag a remote card beyond the right edge of Hive and release to open a
  resizable window. A regular click still opens fullscreen. The client area
  follows the target resolution's aspect ratio, excluding the native caption
  and borders. A native snapshot supplies the provisional ratio; the first
  decoded frame and later resolution changes update it. No snapshot defaults
  provisionally to 16:9. This remains one active remote viewing session.
- Windowed input maps through the client origin and video viewport. Captions,
  borders, other windows and sidebar drags stay local. Focus loss and moving/
  sizing release remote keys/buttons; absolute mouse mode does not trap the
  local pointer. Relative mode confines only the active viewer and releases
  while Hive is open. Close or Ctrl+Alt+` returns locally.
- Connection snapshots follow the floating client area; debug indicators
  follow its top-left. Selection still allocates fresh video/waiting windows
  and retains old renderer leases until workers stop.

Validation: native and WinUI release builds; 32 native CTest checks, including
expanded noninteractive-window-station regressions for reorder/persistence,
drag cancellation, windowed selection, source-ratio changes, all eight sizing
edges, waiting-cover alignment and the existing stale-frame isolation cases.
Input worker regressions cover client coordinates, letterboxes and focus-release
barriers without physical input injection. Actual animation feel and remote
window interaction remain for user validation.
