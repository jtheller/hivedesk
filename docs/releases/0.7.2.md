# 0.7.2

- Delay Connecting and Reconnecting hints by 650 ms. Target snapshots and live
  previews remain immediate; quick connections never flash a waiting badge.
- Cancel the delayed hint when the first frame arrives or the connection is
  canceled, and restart the delay for each selected computer.
- Keep fullscreen remote desktops above ordinary topmost desktop overlays.
  Windowed desktops retain normal window stacking. Hive and its temporary
  taskbar reveal remain available above the fullscreen viewer.
