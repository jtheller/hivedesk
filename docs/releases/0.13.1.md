# 0.13.1

Local performance logging no longer depends on the Debug overlay toggle.
The normal agent records active host/viewer diagnostics by default, including
encoder/decoder pressure, target and capped frame rates, network counters and
input timing. Viewer/input sampling continues with the overlay hidden. The
overlay toggle only controls the on-screen statistics panel.

The existing asynchronous logger writes active-session snapshots roughly once
per second and keeps its two bounded 2 MiB history files. An idle agent waits
for state changes instead of rewriting the same idle snapshot every second.
This logging contains counters and device/session identity, not clipboard
contents, keyboard values or desktop images.

Detailed per-frame CSV tracing is independent and off by default. Developers
can launch the agent with HIVEDESK_EXPERIENCE_TRACE=1 to enable it for that
process. Normal logging and overlay toggles do not turn on the additional
per-frame display-timing queries.

The slowdown badge now reads "Reduced frame rate" instead of "Device busy";
"Slow connection" remains the network-pressure message. The compact badge is
widened to fit the new text. Detection thresholds and streaming/quality/input
policies are unchanged.

Validation covers default-on telemetry, bounded history, quiet idle logging,
and the actual App collecting viewer/input diagnostics with its overlay off.
Existing rapid Peek, windowed switching, nested control/return/summon and
connection recovery tests remain in the release suite.
