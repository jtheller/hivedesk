# 0.7.4

- Fix a viewer driver-lock cycle observed during rapid Peek/switching: serialize
  CUDA map/texture registration/conversion/unmap against that viewer's D3D draw,
  resize and Present calls. Decode, networking and display waits remain separate;
  the latest-picture policy and one-frame display admission are preserved.
- Reconnect on a fresh window and snapshot cover instead of attaching another
  swapchain/composition target to a window whose old renderer is still retiring.
  Discard failed warm surfaces and reject stale preview cancellation by identity.
- Bound graphics preparation to eight seconds. Track foreground and warm resource
  retirement together, suspend speculative warming when retirement stalls, and
  use the supervised restart helper for retirement older than fifteen seconds
  when no healthy viewer, inbound controller or inbound live preview is active.
  This last-resort recovery returns to the local desktop; select a peer again.
  These are lifecycle fault limits, not network latency or frame-rate limits.
- Record graphics preparation/retirement durations and composition HRESULT/stage.
- Strengthen regression coverage with rapid Peek/selection, blocked retirement,
  same-peer recovery, stale completions, and CUDA/Present exclusion. The isolated
  full-App test uses real encrypted transport/NVDEC/drawing with injected Present
  completion because its window station cannot scan out. Separate real DWM pixel
  checks exercise preview replacement, fade reversal, promotion and teardown.

Steady cadence full-screen flashes and 10-bit streaming are not claimed fixed or
implemented by this release. Keep Steady cadence disabled for ordinary use.
