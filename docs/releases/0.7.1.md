# 0.7.1

Fix the SYSTEM broker rejecting the new live-preview message in 0.7.0.
The protocol enum included Peek, but the pipe reader still rejected message
numbers above the previous activation acknowledgement. Hovering therefore
closed the media pipe instead of resuming the warm stream.

- Accept the preview command in the broker framing validator.
- Add a real named-pipe resume/pause/resume regression that fails against 0.7.0.
- Retain the 0.7.0 read-only preview and snapshot-to-live transition changes.

Use 0.7.1 or newer on both computers for live Peek. The installed read-only
preview probes require changing desktop content to verify continuous frames;
a fully static desktop intentionally does not encode duplicate pictures.
