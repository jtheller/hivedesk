# 0.7.11

- Separate predictive-reference decoding from presentation freshness. Intact
  compressed frames may catch up within the existing four-picture ownership
  bound and a one-second excess-transit/local residence ceiling. The latest
  received picture no longer loses its reference chain merely because transport
  jitter exceeded 50 ms. Local prepared output retains its 50 ms deadline;
  missing references, overflow, malformed provenance and severe backlog still
  require recovery. Session and rendering epochs remain isolated.
- Negotiate byte-progress feedback independently of complete decoded pictures.
  A receiver can report an incomplete first IDR; sustained producer blocking
  plus advancing wire bytes can update the network budget during recovery.
  Static desktops, stale reports and decoder backlog do not establish capacity.
  A guessed quality model cannot reduce FPS before actual P-frame QP evidence.
  Older peers keep their previous feedback layout.
- Add explicit, authenticated generated-data TCP/UDP path measurements, bounded
  to 0.1-20 Mbps and 1-10 seconds. UDP data has per-probe authentication and
  duplicate rejection; both transports use incompressible generated payloads.
  No capture, input, clipboard or persistent network setting is involved.
- Include developer tools HiveDeskPathCheck and HiveDeskRemoteVideoCheck. The
  latter measures a bounded read-only live preview; presenting a first picture
  is connectivity evidence, not a smoothness pass.
- Record per-picture wire assembly separately from playback queue age in local
  diagnostics. A short queue does not imply a short end-to-end delay.

This is a reference/feedback correction and measurement release. The production
video lane is still TCP; it does not yet include UDP media, packet loss repair,
FEC or a media packet pacer. Native resolution, HEVC 4:4:4 and QP guardrails remain
unchanged. This release does not claim DEVR is now suitable for interactive use.

Validation before packaging: 42/42 native checks, managed update/GPU policy checks
and real WinUI light/dark checks passed. Actual generated GPU presentation and
250 ms source-stall recovery passed. A hidden HEVC 4:4:4 loopback with delayed
feedback delivered all 510 encoded pictures without sender rejection. Generated
TCP and UDP loopback probes, invalid rate/duration bounds and peer-stop
cancellation passed. These checks do not establish real-peer motion smoothness.
