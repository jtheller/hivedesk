# 0.1.0-alpha.37

Restart HiveDesk now recovers a stuck session even when the media command worker
or shutdown cleanup cannot return.

- The tray action starts an independent helper directly, before input release,
  session locks or queued cleanup. Repeated requests coalesce.
- The helper asks the old agent to close, waits 1.5 seconds, then forcibly ends
  it if necessary. It verifies process identity and waits at most five more
  seconds for Windows to finish termination before reporting failure.
- The SYSTEM service forcibly replaces its own Host child, independently of
  capture/encoding/input cleanup. The console user can request that specific
  operation without receiving permission to terminate arbitrary SYSTEM processes.
- Owned Settings windows are cleaned up too. The replacement returns quietly to
  the tray; preferences remain saved. Manual restart interrupts active sessions.
- `HiveDesk.exe --restart` exposes the same recovery path if the tray itself
  cannot open its menu. Automatic updates retain their idle-session barrier.

Validation: 31/31 native checks passed. Isolated hidden subprocess tests cover
a parked command worker, normal exit, hung shutdown, hung UI, stuck Settings,
missing termination rights, wrong-image/self/nonprocess rejection, and restricted
handle inheritance. No desktop input is injected. These tests do not reproduce
the original GPU-driver stall; Windows/kernel failures can still prevent process
termination, which is reported rather than waited on indefinitely.
