# 0.2.0

HiveDesk now uses regular numbered releases instead of extending the alpha series.

- Fixes and refinements increment the patch version (for example, 0.2.1).
- Feature releases increment the minor version (for example, 0.3.0).
- Alpha/beta/rc suffixes are reserved for explicitly designated preview builds.
- Application, Settings and installer versions now agree on 0.2.0; Windows
  numeric file versions are 0.2.0.0.

This release retains the alpha.39 snapshot waiting screen, fade transitions and
first-Present gate. Existing alpha builds use the same signed OTA path; updates
still require no active, starting or reconnecting remote session. No configuration
reset, protocol migration or manual reinstall is required for OTA-capable builds.

Validation: 32/32 native checks passed. OTA version-order checks cover alpha.39 to 0.2.0, patch/minor upgrades,
and rejection of same-version prerelease downgrades. The 0.x series remains under
active development; adopting plain version numbers does not establish a 1.0
compatibility or hardware-support promise.
