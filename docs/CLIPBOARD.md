# 剪贴板（0.6.0）

两端都更新到 0.6.0 后，照常复制、切换电脑、粘贴即可，不需要设置开关。
支持双向文字、截图／图片、资源管理器里的文件和文件夹。图片保留 PNG、DIB
或 DIBV5 数据，不经视频编码；文件支持多选、子目录和空文件／空目录。

复制时同步文字、图片格式和文件清单；粘贴时按需读取图片或文件内容。
文件通过 Windows 原生 OLE 虚拟文件接口交给目标应用，资源管理器使用自己的
复制过程与进度显示。跨电脑剪切按复制处理，源文件不会被删除。

每次切机仍携带当前剪贴板。刚复制后立即切机，会先确认系统剪贴板序列已经
进入缓存，不使用旧缓存冒充新内容。预热电脑不会得到剪贴板权限。
文件来源电脑需要保持 HiveDesk 运行且可连接；修改、删除源文件或失去来源
连接时，读取会失败，不会用其他文件或新一轮剪贴板内容代替。

文件内容使用独立加密 TCP 通道，单块最大 256 KiB，与视频、输入和控制通道
分离。文件不整份装入内存，也不先下载到临时目录。文件传输正在进行时，
自动更新和 GPU 策略的空闲重启会等待。剪贴板内容和文件路径不写入诊断日志。

当前边界：

- 单份剪贴板图片合计最多 256 MiB，文字最多 1 MiB UTF-16。
- 一次最多 4096 个文件／文件夹条目；每个相对路径少于 260 个 UTF-16 字符。
- 文件流使用 64 位大小和偏移，可处理超过 4 GiB 的文件。
- 不跟随符号链接或目录联接；源文件必须可读且未发生变化。
- 先支持文件管理器的实体文件选择；Outlook 等应用生成的虚拟附件、HTML／RTF
  及跨电脑删除源文件的“移动”语义不在本版范围。
- 与旧版连接时继续使用文字剪贴板；图片和文件需要双方升级。

实现依据：微软的 [Shell 剪贴板格式](https://learn.microsoft.com/en-us/windows/win32/shell/clipboard)
与 [异步数据提取接口](https://learn.microsoft.com/en-us/windows/win32/api/shldisp/nn-shldisp-idataobjectasynccapability)。
