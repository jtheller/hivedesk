# Hive 实时预览

两端更新到 0.7.1 后，打开 Hive 并把鼠标移到其他电脑的卡片上，即可淡入只读实时画面。
移开卡片会淡回原画面；点击卡片才交接键鼠和剪贴板。无需新增设置。

Hive 打开时仍预热所有可见设备，平时只保留一帧；只有悬停的设备连续出帧。
预览不能抢占已经被其他连接占用的主机。预热被拒绝或失败时，保留原画面和卡片，
不以空白预览代替。旧版设备仍可正常点击连接，但不会开启实时预览。

点击已显示的全屏预览直接沿用该画面；拖出卡片仍进入可调整大小的窗口模式。
窗口大小改变后必须等新帧提交完成，才撤去对应机器的等待画面。

只读诊断：已安装的主程序支持 `--peek-broker-check`；检查程序支持 `--peek`
或 `--peek-remote <IPv4>`。这些检查会请求视频，但不发送输入、不改剪贴板；
已有连接占用主机时应等待空闲再运行。
连续帧诊断需要桌面上有持续变化的内容；完全静止时不会重复编码相同画面。
