## 已实现的主要约定

- 无中央服务器的局域网自动发现和点对点连接；常规设置不要求 Network Key 或手填 IP。
- 登录自启、托盘、双击托盘设置、Hive 热键、固定大小的 WinUI 设置、图标和版本显示。
- 固定逃生键、踢人键、相对鼠标复选框、独立辅助进程执行的强制重启。
- 快照、等待过渡、不同机器的新视频窗口隔离；拖拽排序持久化、跟手卡片、让位动画。
- 拖出打开窗口、等比缩放；0.3.2 增加最大化／还原和 300ms 的热键错峰入场。
- 文本剪贴板切换交接、光标同步、锁屏输入及登录后的捕获恢复、断线重连。
- 目标帧率取两端主屏刷新率较低值，不修改物理显示模式；性能设置由自动策略管理。
- 左上角实时诊断、异常颜色、半透明可穿透底色、异常提示和两端版本号。
- GitHub 公共仓库、逐版本 Release、签名校验、空闲 OTA、检查更新按钮。0.3.1 已真实 OTA 安装并核验二进制，且本机日志记录了 VI、6RE 的实际视频启动成功。

当前仍只有一个主动观看会话：窗口模式不会新增多个同时播放的远端窗口。此前没有明确要求同时多窗口。
Win8 交互是自写的仿制实现，并非原版动画的逐帧复制；当前按用户要求定制了错峰时间。

## 明确暂缓或不做

- 音频；多显示器；图片／文件剪贴板；专门的休眠／唤醒恢复流程。
- 非 US 键盘布局和本地输入法转发：中文输入法仍由被控机处理。
- 防套娃：用户已取消，不列为待交付。
- 最初“不处理掉线”的约定已被后续重连要求取代；重连已实现，不能继续归为不做。

50ms 帧新鲜度、有限在途数量属于当前调度策略，仍然存在；秒级故障超时已放宽。没有把“移除不必要限制”理解成取消所有缓冲和过期保护。上述长 RTT 问题解决前，也不声称这些策略已适配所有网络。
